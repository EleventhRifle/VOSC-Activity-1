# VOSC Activity-1 — Tic-Tac-Toe

A simple, fully playable two-player Tic-Tac-Toe game built with only **HTML, CSS and JavaScript** — no frameworks, no build step, no dependencies.

## Project structure

```
VOSC Activity-1/
├── index.html   # page structure (board, status, scoreboard, buttons)
├── style.css    # layout and styling
├── script.js    # game logic (turns, win/draw detection, scores)
└── README.md
```

## How to run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser (double-click the file).

That's it — no server or installation needed.

## How to play

- Two players share one screen: **X** goes first, then **O**.
- Click an empty square to place your mark.
- The first player to get **three in a row** (horizontal, vertical or diagonal) wins; the winning line is highlighted.
- If all nine squares fill up with no winner, the round is a **draw**.
- **New round** clears the board (the starting player alternates each round). **Reset scores** sets all scores back to zero.

## Features

- Win and draw detection
- Running scoreboard for X, O and draws
- Winning squares highlighted
- Responsive layout (works on phones and desktops)
- Keyboard accessible (Tab to a square, Enter/Space to play)

## Technologies

HTML5 · CSS3 · Vanilla JavaScript
